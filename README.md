# starter-agent

A blank starting point for building a persistent autonomous agent using
Claude Code, [agent-portal](https://github.com/robhunter/agent-portal),
and [agentbox](https://github.com/robhunter/agentbox). Clone this repo,
have a 15-25 minute conversation with Claude about who you are and what
you want help with, and end with an agent that wakes on a schedule to
do work for you.

**Similar in shape to Bobbo** — a personal research agent running in
Docker, journaled via Git, and monitored via a web portal.

## Setup

See [SETUP.md](./SETUP.md) for the full walkthrough. Plan for ~1 hour
end to end.
